# Obligations & Contracts Learning Hub

An interactive academic study guide web application built for the Civil Code of the Philippines (Obligations & Contracts).

## Project Structure
```
├── assets/         # Static media & assets
├── css/            # Compiled stylesheets
├── js/             # JavaScript application logic
├── manual/         # Documentation & user manuals
├── scss/           # Source SASS/SCSS files
├── index.html      # Main HTML interface entrypoint
└── README.md       # Project documentation
```

## Features
- **Lessons & Articles:** Detailed legal breakdown of Articles 1156, 1157, 1163-1174, 1305, 1318, 1380, and 1409.
- **Flashcards Glossary:** Interactive flip cards covering legal terms like *Solutio Indebiti*, *Negotiorum Gestio*, *Mora Solvendi*, etc.
- **Contract Validator Tool:** Real-time evaluator testing contract status (Valid, Voidable, Rescissible, Void).
- **Interactive Quiz:** 8-question self-assessment with score feedback.
- **Saved Reviewer:** LocalStorage bookmarking functionality for quick revision.
